# wbushey.com 

Forked from [Jacob Tomlinson](https://twitter.com/_JacobTomlinson)'s 
[Carte Noire](https://github.com/jacobtomlinson/carte-noire) Jekyll theme. 

Installing
==========

Ruby version is managed via asdf. Install the [ruby plugin](https://github.com/asdf-vm/asdf-ruby).

Then run `asdf install`

Then, to install all dependencies:

```
bundle install
```

Building and Serving
====================

To serve on port 4000 and rebuild while adding content or developing:

```
bundle exec jekyll serve --livereload
```

Publishing
==========

Create a pull request to main in Github. Once merged, Github Pages will deploy to https://www.wbushey.com
